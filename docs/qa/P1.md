- B2 PostgreSQL/MongoDB: neither app is installed.
- B4 SSH update: the panel exposes local SSH connectivity through
  `/settings/ssh/check`, which now runs before and after a port change. The
  actual port change still needs a second session and was not executed.
- C1 ClamAV/Fail2ban: neither service is installed. The ClamAV create form now
  exposes the none/remove/move/copy infected-file strategy and infected
  directory, but the EICAR scan acceptance still needs a panel with ClamAV.
- C2 PHP extensions: no PHP runtime is installed. The extension tab now has
  an explicit refresh action; the panel has no per-extension version update.
- B3 chunk resume: the resumable `uploadID`/`offset`/`fileSize` fields are wired
  but a multi-gigabyte pause/resume run still needs a device and a large file.
