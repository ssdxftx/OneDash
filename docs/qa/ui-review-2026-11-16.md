### 审查方法

使用 Flutter Widget Test 加载真实页面、主题、字体与图标资源，接入可控的假数据，覆盖主流程页面和关键异常数据，再逐张检查截图，并对照代码确认布局与文案来源。

说明：

- 截图在测试渲染环境中生成，模拟了状态栏高度，没有真实 Android 手势条与系统字体差异。
- 图表刻度由 Canvas 直接绘制，测试环境默认字体会把部分刻度显示成色块。图表相关结论以代码路径为准。
- 本轮视觉审查覆盖 8 个主流程页面；其余页面以代码走查为主。

## 1. 结论摘要

整体设计系统完成度较高，token、卡片、状态色、三态视图、深色主题和动效降级都有统一实现。当前问题集中在四个层面：

1. 窄屏与大字号适配不足，320dp 下出现布局溢出和标题消失。
2. 关键数据在 390dp 正常字号下已经被截断，影响阅读。
3. 网站状态与类型存在错误文案，高负载资源又使用“健康绿”，语义会误导用户。
4. 一级页面的信息架构和操作入口不一致，影响可发现性。

问题统计：

| 等级 | 数量 | 说明 |
|---|---:|---|
| P0 | 4 | 可复现的布局错误、错误状态文案、关键数据不可读 |
| P1 | 6 | 语义误导、入口不一致、可访问性不足 |
| P2 | 4 | 图表细节、本地化、一致性与视觉节奏 |

## 3. 详细问题

### P0-01 320dp + 1.25x 布局溢出与标题消失

**现象**

- 概览页服务器卡片的四列指标触发 `RenderFlex overflowed by 1.0 pixels`，测试框架捕获到布局断言。
- 运行时长显示为 `11天 1...`，负载显示为 `1.24/...`，第 5、15 分钟负载完全丢失。
- 容器列表在 320dp 下标题完全不可见，只剩服务器副标题 `新...`。
- 容器名称压缩为 `acm...`，端口显示为 `80:80,...`、`3306:3...`。
- 设置页主题模式第一个标签显示为 `跟...`。

**证据**

- `当前工作区/tool/ui_audit/shots/overview_dark_320_text125.png`
- `当前工作区/tool/ui_audit/shots/containers_dark_320_text125.png`
- `当前工作区/tool/ui_audit/shots/settings_dark_320_text125.png`

**原因**

- 概览指标固定为四列，每列约 64dp，标签为 10sp 且没有 `Flexible`，`lib/presentation/features/dashboard/widgets/dashboard_cards.dart:260`。
- 容器列表标题栏同时放置 4 个动作，窄屏没有折叠策略，`lib/presentation/features/containers/screens/containers_page.dart:215`。
- 设置页三段式标签不可滚动，长文案只能省略，`lib/presentation/features/settings/screens/app_settings_page.dart:60`。

**建议**

- 指标区按宽度切换为 2×2 布局，或把“架构 / 进程数”降级到第二行。
- `AppBarLarge` 增加动作溢出菜单，窄屏最多保留两个高频动作。
- 分段控件在窄屏改为可滚动，或使用“系统 / 浅色 / 深色”。
- 容器卡片把状态、播放按钮、Compose 徽章移到第二行，名称允许两行。

### P0-02 390dp 下关键数据已被截断

**现象**

- 概览负载值 `1.24/1.08/...` 丢失后半段。
- 磁盘容量 `110 GB / 120 ...` 看不到总量。
- 容器列表副标题 `新加坡生产环境 ...` 丢失容器总数。
- 网站列表第一个长域名显示为 `www.acme-corporatio...`，路径也同步截断。

**证据**

- `当前工作区/tool/ui_audit/shots/overview_light_390.png`
- `当前工作区/tool/ui_audit/shots/containers_light_390.png`
- `当前工作区/tool/ui_audit/shots/websites_light_390.png`

**原因**

- 资源行把数值与百分比放在同一行，`lib/presentation/features/dashboard/widgets/dashboard_cards.dart:383`。
- 网站域名只允许单行，右侧同时放状态、SSL 徽章和箭头，`lib/presentation/features/websites/screens/websites_page.dart:1316`。
- 容器副标题把服务器名和数量拼成一行，`lib/presentation/features/containers/screens/containers_page.dart:207`。

**建议**

- 资源行把百分比单独占一列或单独一行，优先保证容量可读。
- 网站卡片把状态和 SSL 徽章移到第二行，域名允许两行。
- 容器副标题在窄屏只显示服务器名，数量改到筛选区或卡片角标。

### P0-03 网站证书过期文案错误

**现象**

- 已过期证书显示为 `剩余 -6 天`，语义和文案都不成立。

**证据**

- `当前工作区/tool/ui_audit/shots/websites_light_390.png`

**原因**

- 直接使用 `websites_expire_days(daysLeft)`，没有处理负值，`lib/presentation/features/websites/screens/websites_page.dart:1402`。

**建议**

- 增加 `websites_expired_days` 文案。
- 负天数显示“已过期 N 天”，0 天显示“今天到期”。
- 过期状态继续使用 danger 色。

### P0-04 网站类型映射缺失

**现象**

- `runtime`、`deployment` 类型的网站显示为“未知”。
- 运行日志连续出现 `[enum_labels] unmapped value: runtime/deployment`。

**证据**

- `当前工作区/tool/ui_audit/shots/websites_light_390.png`

**原因**

- 映射只覆盖 `static`、`proxy`、`php`，`lib/presentation/common/formatters/enum_labels.dart:65`。

**建议**

- 补齐 `runtime`、`deployment`、`subsite`、`stream`。
- 复用已有文案键：`websites_runtime`、`websites_deployment`、`websites_subsite` 等。
- 删除或降低 unmapped 日志级别，避免正式包持续输出。

### P1-01 高负载仍然显示为健康色

**现象**

- 概览中 CPU 91% 是绿色，内存 88% 是紫色，磁盘 92% 才是红色。
- 服务器列表的 CPU 91%、内存 88%、磁盘 92% 三个环全部为绿色。

**证据**

- `当前工作区/tool/ui_audit/shots/overview_light_390.png`
- `当前工作区/tool/ui_audit/shots/overview_dark_390.png`
- `当前工作区/tool/ui_audit/shots/servers_light_390.png`

**原因**

- CPU 固定使用 `success`，内存固定使用 `chart4`，只有磁盘调用 `_usageColor`，`lib/presentation/features/dashboard/widgets/dashboard_cards.dart:314`、`:327`、`:342`。
- 服务器迷你环没有传入严重度颜色，`lib/presentation/features/servers/screens/servers_page.dart:577`。

**建议**

- 进度条和百分比统一使用 60% / 85% 阈值。
- 图标底色保留资源身份色，严重度只体现在进度条和百分比上。

### P1-02 文件页缺少服务器上下文

**现象**

- 文件页是唯一不显示服务器名称的一级 Tab。
- 标题使用 16sp 文件夹名，其他一级 Tab 使用 24sp 大标题。
- 标题不可点击，没有服务器切换入口。

**证据**

- `当前工作区/tool/ui_audit/shots/files_light_390.png`

**原因**

- 文件页使用紧凑 `AppBar`，标题只放文件夹名，`lib/presentation/features/files/screens/files_page.dart:1179`。

**建议**

- 标题栏显示“文件夹名 + 服务器名”，支持点击切换服务器。
- 与网站、容器、更多页统一标题层级。
- 上传、排序、更多可收进溢出菜单，保留搜索和新建为主操作。

### P1-03 文件面包屑与行尾箭头

**现象**

- 根目录标题是“根目录”，面包屑第一项是“主目录”，文案冲突。
- 面包屑只有文字，没有 `/` 或箭头分隔，多级路径层级不清晰。
- 根目录下面包屑只有“主目录”，信息重复。
- 所有文件都显示行尾箭头，点击文件却打开操作菜单。
- 每个文件夹副标题都重复显示“文件夹”。

**证据**

- `当前工作区/tool/ui_audit/shots/files_light_390.png`

**原因**

- 面包屑实现位于 `lib/presentation/features/files/screens/files_page.dart:1750`。
- 行尾箭头固定显示，`lib/presentation/features/files/screens/files_page.dart:1894`。
- 文件夹副标题逻辑位于 `lib/presentation/features/files/screens/files_page.dart:1874`。

**建议**

- 面包屑加入分隔符，根目录显示 `/` 或统一为“根目录”。
- 根目录隐藏重复项。
- 文件夹使用箭头，文件使用更多图标。
- 文件夹副标题显示子项数量，或直接移除。

### P1-04 网站页操作可发现性

**现象**

- 标题栏只有 `...` 一个动作，搜索、新建、分组、模板等入口都需要先打开菜单。
- 顶部 `...` 与底部“更多”Tab 的三点图标同时出现，含义不同。
- 筛选条在 390dp 下只能完整显示 4 个，`运行环境` 被裁掉，横向滚动提示不明显。

**证据**

- `当前工作区/tool/ui_audit/shots/websites_light_390.png`
- `当前工作区/tool/ui_audit/shots/websites_dark_390.png`

**原因**

- 标题栏动作集合为 `[_moduleMenu(...)]`，`lib/presentation/features/websites/screens/websites_page.dart:286`。
- 筛选条为横向滚动 chips。

**建议**

- 增加可见的新建主按钮与搜索图标，其余操作进溢出菜单。
- “更多”Tab 改用网格或列表图标，与溢出菜单区分。
- 筛选条在窄屏换行或缩短标签，保留至少 5 个可见筛选项。

### P1-05 “容器”Tab 的落地页语义

**现象**

- 底部 Tab 叫“容器”，点击后进入 Docker 概览。
- 真正的容器列表在更深一层路由。
- Docker 概览的第一行也叫“容器”，两个同名入口去向不同。

**证据**

- `当前工作区/tool/ui_audit/shots/docker_overview_light_390.png`
- `当前工作区/tool/ui_audit/shots/containers_light_390.png`

**原因**

- `/s/:id/containers` 指向 `DockerOverviewPage`，`lib/core/router/app_router.dart:294`。
- 容器列表位于 `containers/list` 子路由。

**建议**

- Tab 改名为“Docker”，或直接落地容器列表，并在顶部提供 Docker 概览入口。
- 保持 Tab 名称、页面标题、首个入口名称一致。

### P1-06 可访问性

**现象**

- 概览指标标签、状态胶囊使用 10sp，图表图例 11sp，低于项目自身 12sp 的正文下限。
- 服务器编辑按钮、容器暂停按钮使用 `VisualDensity.compact`，实际点击区小于常规 48dp。
- 强调色选择只有 8 个彩色圆点，没有名称和语义标签。

**证据**

- `当前工作区/tool/ui_audit/shots/overview_light_390.png`
- `当前工作区/tool/ui_audit/shots/settings_light_390.png`

**原因**

- `lib/presentation/features/dashboard/widgets/dashboard_cards.dart:229`、`:271`、`:781`
- `lib/presentation/features/servers/screens/servers_page.dart:460`
- `lib/presentation/features/containers/screens/containers_page.dart:648`
- `lib/presentation/features/settings/screens/app_settings_page.dart:194`

**建议**

- 辅助文字与状态文字不低于 12sp。
- 图标按钮统一包裹 48dp 命中区。
- 强调色增加 tooltip 与语义标签，例如“森林绿，已选中”。

### P2-01 图表细节

**现象**

- 速度图最后一个 Y 轴刻度在 `y = height` 时仍绘制到 `y + 6`，超出画布被裁掉。
- Y 轴刻度绘制在绘图区内部，与数据线重叠。
- 没有时间轴标签，用户无法判断曲线对应的时间范围。
- 图例固定宽度 78、字号 11，大字号下容易截断。

**原因**

- `lib/presentation/features/dashboard/widgets/dashboard_cards.dart:770-785`
- 图例宽度定义在 `lib/presentation/features/dashboard/widgets/dashboard_cards.dart:709`

**建议**

- 图表左侧留出刻度槽，跳过越界刻度。
- 底部补 `-60s / -30s / now` 时间标签。
- 图例改用 `Flexible`，字号不低于 12sp。

### P2-02 本地化与文案一致性

**现象**

- `7.31 / 8 Cores` 硬编码英文，项目里已有 `dashboard_cores`。
- 中英文混排：`Swap`、`Compose`、`编排模板`、`Cores`。
- 服务器头部副标题出现 `Ubuntu 24.04 LTS · 24.04 LTS`，版本重复。
- 网络卡片只写“上传 / 下载”，没有说明累计流量还是实时速率。
- 根目录标题“根目录”与面包屑“主目录”不一致。

**原因**

- `lib/presentation/features/dashboard/widgets/dashboard_cards.dart:319`
- 副标题拼接位于 `lib/presentation/features/dashboard/widgets/dashboard_cards.dart:136`
- 文案键位于 `lib/core/localization/l10n/app_zh.arb:309`

**建议**

- 使用 `dashboard_cores` 替换硬编码。
- `Compose` 统一为 `Compose` 或统一为“编排”，不要两种混用。
- 副标题去重，`prettyDistro` 已包含版本时不再拼接 `platformVersion`。
- 网络卡片增加“累计流量”说明。

### P2-03 状态语义与设置一致性

**现象**

- 概览离线胶囊用警告橙，服务器列表离线状态用危险红。
- 新服务器如果从未连接但当前在线，底部显示“离线”，右侧同时显示“在线”。
- OLED 开关在浅色模式下仍可操作，切换后没有可见效果。
- 深色主题背景固定为森林绿基色，切换强调色不会改变背景色。
- 网站进入多选时标题栏从 84dp 降到 64dp，出现高度跳动。

**原因**

- 概览离线使用 warning，`lib/presentation/features/dashboard/widgets/dashboard_cards.dart:209`。
- 服务器底部状态只判断 `lastUsedAt`，`lib/presentation/features/servers/screens/servers_page.dart:539`。
- OLED 开关未与主题模式联动，`lib/presentation/features/settings/screens/app_settings_page.dart:104`。
- 深色 surface 固定色值，`lib/core/theme/app_theme.dart:38`。
- 多选标题栏高度 64dp，`lib/presentation/common/components/selection_app_bar.dart:20`。

**建议**

- 离线统一使用 danger 色。
- 底部状态区分“从未连接 / 最后在线 / 当前离线”。
- OLED 开关在浅色模式下禁用并说明仅在深色生效。
- 深色背景改为从 seed 派生，或明确说明背景不随强调色变化。
- 多选标题栏保持与正常标题栏同高。

### P2-04 视觉节奏与细节

**现象**

- “更多”页三类分组中，有的行有副标题、有的没有，行高在 56/72 之间跳动。
- 网站卡片中的路径和域名高度重复，长路径进一步挤压信息。
- 设置页主题模式分段控件左右内边距不对称，底部整条分隔线与卡片内容不对齐。
- 网站筛选条在 390dp 下显示不全。

**建议**

- “更多”页统一行高，或统一补充副标题。
- 网站卡片优先显示站点目录名，路径在详情页展示。
- 分段控件在卡片内使用对称内边距，分隔线只覆盖控件宽度。
- 筛选条在窄屏换行或使用更短标签。

## 4. 已确认良好的部分

- 设计 token 覆盖完整，页面基本没有散落的魔法数字。
- 卡片、圆角、分隔线、状态点、空态、错误态高度统一。
- 深色主题对比度、按钮可达性、Tooltip、减少动效支持比较到位。
- 列表骨架、下拉刷新、批量选择、危险操作确认的交互成本控制良好。
- 文件、容器、网站的筛选和搜索都有防抖与保留旧数据逻辑。
- 页面内容有最大宽度约束，平板布局不会无限拉伸。
- 底部导航在滚动时自动隐藏，滚动停止区域判断比较细致。
