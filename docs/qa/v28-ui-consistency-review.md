# OneDash UI 一致性与细节审查回执（v28）

## 审查范围

- 全部 70+ 个 presentation 页面与通用组件。
- 设计 token、主题、字体层级、卡片、按钮、输入框、Sheet、分段控件、图表、日志控制台。
- 主列表、详情、表单、向导、工具页的加载/空/错误三态。
- 320dp 窄屏、1.3x / 1.5x 字体、多选态、危险操作、刷新与分页反馈。

## 本轮修复

### 全局

- 标题栏支持点击切换服务器，补语义按钮与无障碍标签；箭头不再是无效暗示。
- 文字层级重新拉开，消除字号倒挂；新增层级回归测试。
- 卡片补 1px 边框，暗色与 OLED 下分组边界可辨。
- 输入框与筛选 chip 边框改用 `outline`，提高非文本边界对比度。
- 危险操作统一使用 `DangerButton`，避免主色删除按钮。
- 错误单行文案改为本地化模板，英文不再出现全角冒号。
- 分段控件补选中语义、索引越界保护与 Reduce Motion。
- 骨架列表真正使用 `itemHeight`，尺寸与真实行高一致。
- Toast、日志控制台、终端按键区改用 token；终端确认改用统一确认 Sheet。
- 窄屏或大字号时底部导航自动改为仅显示选中标签。

### 列表与主流程

- 文件、网站、容器、主机证书的批量选择改为独立选择态；未进入选择态不再常驻 Checkbox。
- 文件三点按钮修复为打开动作菜单，不再误触发选择。
- 文件标题栏与底栏去重，创建入口收为图标按钮，面包屑提升到 48dp 触控高度。
- 容器标题栏 7 个动作收敛为 4 个，其余进入溢出菜单。
- 网站、容器、文件搜索增加 300ms 防抖；刷新与搜索保留旧数据，不再整屏闪骨架。
- 主列表空态支持下拉刷新；网站补刷新入口。
- 应用商店补服务器副标题与切换入口，网格改用主高度适配字体缩放，两个 Tab 支持下拉刷新。
- More 页改为吸顶 Sliver 标题栏，计数加载时不再显示误导性的 `-`。
- 服务卡下拉刷新同时刷新健康指标；离线改用危险语义色。
- 筛选或搜索变化时清空隐藏的已选项，避免误删不可见资源。
- SSL 徽章按到期状态着色，不再过期仍用主色。

### 详情、表单与工具页

- Supervisor 与定时任务记录 Sheet 修复无界 `Flexible` 导致的打开崩溃。
- 安装应用任务超时改为抛错，不再把未完成当成功；卸载默认不删除数据库。
- 应用已安装时安装按钮直接禁用；终端按钮在无容器时禁用；忽略更新菜单按状态切换。
- 服务器编辑加载失败不再永久卡在加载态，补错误态与重试；HTTPS 开关独立成行。
- 数据库类型查询失败不再伪装成空列表；远程实例 4 个图标收为菜单；无实例时禁用保存。
- 网站高级页配置加载成功后才显示编辑器；补路径鉴权刷新；访问认证预填已有账号并校验用户名。
- 反向代理、路径鉴权表单改为弹层内校验，不再关闭后才静默丢弃。
- 反向代理删除提示修正；证书账户菜单补齐跳转。
- 容器详情只在日志 Tab 轮询，停止容器不再显示运行态；镜像名可省略。
- 防火墙搜索/筛选无结果有独立空态与清除入口，搜索按钮始终可见。
- 备份、进程、运行时补可见更多入口，不再只能长按。
- 日志中心行可点开完整内容；告警日志为空时清除按钮禁用；快照描述保存补反馈。
- 面板设置 API 行文案去重；SSL 模式、证书来源、语言补齐本地化。
